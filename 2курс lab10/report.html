1. Как запустить

  1. Полностью распакуйте ZIP. Все папки внутри Lab10_ESModules должны остаться вместе.
  2. Для запуска на компьютере нужен Python 3 и современный браузер.
  3. Откройте Терминал в папке Lab10_ESModules и выполните:
python3 start.py

На Mac также можно открыть START_MAC.command. Если файл не разрешено запускать, используйте команду выше. На Windows откройте START_WINDOWS.bat; он запускает py -3 start.py либо python start.py.

Сервер откроет браузер. Если вкладка не появилась, перейдите на http://127.0.0.1:8000. Оставьте окно Терминала открытым; Ctrl+C останавливает сервер. На странице index.html доступны вкладки «Базовый», «Средний» и «Повышенный». Ссылка внизу страницы открывает report.html.

Устанавливать пакеты через npm или pip не требуется. Python раздает готовые файлы, а JavaScript выполняется в браузере. Открывайте страницу через HTTP: прямое открытие index.html как file:// мешает загрузке ES-модулей. MDN: Modules

Запасной способ запуска из папки проекта:

python3 -m http.server 8000 --bind 127.0.0.1

Затем вручную откройте http://127.0.0.1:8000. Если порт занят, замените в команде 8000 на 8001 и откройте http://127.0.0.1:8001. На Windows вместо python3 используйте py -3. Возможности локального сервера описаны в документации Python.

6. Ключевые листинги и схема импортов

Подключение в index.html:

<script type="module" src="./src/main.js"></script>

Именованный экспорт из src/modules/basic/temperature.js:

export function celsiusToFahrenheit(celsius) {
  return celsius * 1.8 + 32;
}

Импорты из src/modules/basic/main.js:

import { convertTemperature, getFormula, parseTemperature } from './temperature.js';
import createTemperatureUI, {
  clearTemperatureResult,
  showTemperatureError,
  showTemperatureResult,
} from './ui.js';

createTemperatureUI объявлен как export default function createTemperatureUI(root). Он импортируется без фигурных скобок, а именованные экспорты — в скобках. Одновременно использовать оба вида экспорта разрешено. MDN: export

Пример операции модели из src/modules/advanced/contacts.js:

export function deleteClient(clients, id) {
  if (!getClientById(clients, id)) throw new Error("Клиент для удаления не найден.");
  return clients.filter((client) => client.id !== id);
}

Функция возвращает новый массив и не обращается к странице. Обработчик в main.js сохраняет полученный массив и просит ui.js перерисовать таблицу.

Импортирующий файл Откуда импортирует

basic/main.js temperature.js, ui.js

Циклов нет: модели и общие модули не импортируют обработчики. Изменение разметки затрагивает ui.js, изменение формул — temperature.js, правил клиента — validation.js. Дополнительный модуль storage.js используется двумя приложениями без копирования его кода.

7. Данные, ограничения и обработка ошибок

Списки задач и клиентов первоначально пусты. Конвертер ничего не сохраняет. Задачи записываются под ключом lab10.tasks.v1, клиенты — lab10.crm.clients.v1 в localStorage. Данные принадлежат этому браузеру и адресу страницы; другой порт или другой браузер использует отдельное хранилище. Очистка данных сайта удаляет записи. MDN: localStorage

При ошибке чтения JSON приложение начинает с пустого списка; записи неверной структуры пропускаются. Если сохранение недоступно, на странице появляется сообщение, а текущие изменения остаются в памяти вкладки. Это учебная CRM: общей серверной базы, учетных записей и синхронизации между пользователями нет.

10. Ответы на контрольные вопросы

Нумерация 9–20 сохранена из задания.

9. Что такое модуль в JavaScript?

Это отдельная единица кода со своей областью видимости. export открывает нужные функции и данные для других модулей, а import подключает их. MDN: Modules

10. Чем ES-модули отличаются от обычных скриптов?

ES-модули поддерживают статические import/export, выполняются в строгом режиме и имеют собственную область видимости. Их зависимости загружаются по импортам. MDN: import

11. Для чего нужен type="module"?

Он сообщает браузеру, что подключенный скрипт нужно интерпретировать как ES-модуль. В проекте этот атрибут стоит у подключения src/main.js. MDN: import

12. Как работает именованный export?

Он публикует значение под определенным именем: например, export function convertTemperature(...). Другой файл использует import { convertTemperature } from './temperature.js'; при необходимости имя можно переименовать через as. MDN: export

13. Чем default export отличается от named export?

Именованных экспортов в модуле может быть несколько, а экспорт по умолчанию — один. Обычная форма импорта default не требует фигурных скобок и позволяет выбрать локальное имя. MDN: export

14. Почему важен путь к импортируемому файлу?

По этому пути среда находит модуль. В нашем проекте относительный путь считается от импортирующего файла; важны имя, регистр символов и расширение .js. MDN: import

15. Что такое область видимости модуля?

Это граница доступности его переменных и функций. Объявления верхнего уровня модуля не становятся автоматически свойствами window; другие модули получают доступ через экспорты. MDN: Modules

16. Почему модульное приложение удобнее сопровождать?

У каждого файла есть понятная задача. Например, изменение формулы температуры не требует изменения таблицы CRM; общий модуль хранения исправляется один раз для двух приложений.

17. Зачем отделять бизнес-логику от DOM?

Так функции можно проверять без браузера и повторно использовать с другой разметкой. В этом проекте тесты вызывают convertTemperature, addTask и addClient непосредственно.

18. Как диагностировать ошибку загрузки модуля?

Откройте DevTools → Console и Network. Проверьте текст ошибки, адрес запроса, наличие файла, HTTP-статус и JavaScript-тип ответа, затем соответствие import и export. MDN: Modules

19. Почему рекомендуется запускать проект через HTTP-сервер?

При открытии через file:// браузер может блокировать загрузку модулей из-за правил происхождения ресурсов. Локальный HTTP-сервер обеспечивает обычные запросы по URL. MDN: Modules

20. Что такое циклическая зависимость модулей?

Это ситуация, когда A импортирует B, а B прямо или через другие файлы зависит от A. Иногда она вызывает обращение к еще не инициализированному значению; в данном проекте таких циклов нет. MDN: Modules
